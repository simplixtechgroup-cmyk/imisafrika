METTRE EN LIGNE
---------------
Option A : GitHub Pages (adresse actuelle)  -> déposer tout le contenu du dossier dans le dépôt, activer Pages.
Option B : Netlify ou Cloudflare Pages      -> glisser-déposer le dossier ; _headers est pris en compte.
Option C : hébergement classique (o2switch, OVH, PlanetHoster...) -> envoyer tout le contenu, y compris les
           fichiers cachés (.htaccess, .well-known), à la racine du site ; le HTTPS est alors forcé par .htaccess.

AVEC UN NOM DE DOMAINE (recommandé pour impressionner le client)
----------------------------------------------------------------
Les adresses (canonique, partage, sitemap) pointent aujourd'hui vers
https://simplixtechgroup-cmyk.github.io/imisafrika/
Dès que le domaine est choisi, exécuter une seule commande, puis republier :
    python3 outils/changer-domaine.py https://www.imisafrika.com/
(ajouter --dry-run pour voir ce qui sera modifié sans rien changer)

APRÈS LA MISE EN LIGNE : CONTRÔLES À FAIRE
------------------------------------------
 1. Coller l'adresse du site dans WhatsApp : l'aperçu (image + titre) doit s'afficher.
    Si l'ancien aperçu reste en mémoire : https://developers.facebook.com/tools/debug/ (bouton « Récupérer à nouveau »).
 2. Google Search Console : ajouter le site, envoyer sitemap.xml, demander l'indexation de la page d'accueil.
 3. Créer / revendiquer la fiche Google Business Profile (adresse Zopah, horaires, téléphone).
 4. Tester sur un vrai téléphone : menu, filtres, boutons WhatsApp, formulaire.
 5. Une fois le HTTPS validé, activer la ligne « Strict-Transport-Security » (en commentaire dans _headers et .htaccess).
